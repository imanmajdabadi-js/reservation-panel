# سامانه مدیریت رزرو

داشبورد ریسپانسیو فارسی و راست‌چین برای ثبت و پیگیری رزروها؛ ساخته‌شده با React و TypeScript.

## Tech Stack

- React 19, TypeScript, and Vite
- Material UI 6 and Emotion with RTL support
- `date-fns-jalali` for Jalali date display
- `pnpm` for dependency management

## Installation and Running

```bash
pnpm install
pnpm run dev
```
